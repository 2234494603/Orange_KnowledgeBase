LVGL UI Designer 新手手册

离线可用 LVGL 9.x / master Designer 2.0.5

先用中文理解 Designer 里的属性、样式、状态、事件和动作，再沿着“初始化 → 显示 → 输入 → 控件 → 事件 → 页面”的路线，把界面真正跑起来。

一、核心概念

English 中文 说明
Property 属性 控件自身的数据和行为，例如位置、尺寸、文字和数值
Style 样式 控件的外观，例如颜色、字体、边框和圆角
Part 样式部件 控件内部可单独设置样式的区域
State 状态 控件当前的视觉状态
Event 事件 什么时候触发逻辑
Action 动作 事件发生后执行什么
Action Params 动作参数 动作的目标和具体配置

状态不是事件：pressed 是按下时的视觉状态，LV_EVENT_PRESSED 是按下时触发的逻辑事件。

七、页面事件类型

当前版本为页面开放 46 个事件。页面开发优先使用“生命周期、手势、页面点击和按键”事件；数值、选中和文本类事件通常属于具体控件，不建议直接绑在页面上。

页面生命周期事件

英文事件 中文含义 准确触发时机 常见用途 注意事项
LV_EVENT_SCREEN_LOAD_START 页面开始加载 页面切换流程刚开始、页面尚未完全显示 预设属性、准备数据、设置初始状态 不适合执行依赖页面已经显示完成的逻辑
LV_EVENT_SCREEN_LOADED 页面加载完成 页面已经完成加载并进入显示状态 启动入场动画、刷新数据显示、启动定时器、延迟自动跳转 自动跳转时需防止目标页再次跳回造成循环
LV_EVENT_SCREEN_UNLOAD_START 页面开始卸载 页面即将离开、卸载流程刚开始 停止动画、暂停任务、记录离开前状态 耗时操作可能影响页面切换流畅度
LV_EVENT_SCREEN_UNLOADED 页面卸载完成 页面已经退出显示状态 释放页面资源、完成清理 若启用了自动删除旧页面，不要再访问已删除的页面对象

页面点击、按压和长按事件

英文事件 中文含义 页面用途 建议
LV_EVENT_CLICKED 页面完整点击，松开后触发且未滚动 点击空白区域关闭弹窗、返回或唤醒界面 常用，但要留意子控件事件冒泡
LV_EVENT_SHORT_CLICKED 页面短按点击 只响应短按、不响应长按 按需使用
LV_EVENT_SINGLE_CLICKED 页面单击 区分单击、双击和三击 按需使用
LV_EVENT_DOUBLE_CLICKED 页面双击 双击唤醒、放大或进入特殊界面 按需使用
LV_EVENT_TRIPLE_CLICKED 页面三击 隐藏入口、工程模式入口 少用，注意防误触
LV_EVENT_PRESSED 页面刚被按下 触摸时立即反馈、记录按下起点 按需使用；普通点击优先用 CLICKED
LV_EVENT_PRESSING 页面持续被按住 连续调节、拖动过程或按住检测 高频事件，回调必须轻量
LV_EVENT_PRESS_LOST 按住后手指或光标滑出页面 取消按压操作、复位临时状态 按需使用
LV_EVENT_RELEASED 页面被松开 无论是否形成点击都处理松手 与 CLICKED 的触发条件不同
LV_EVENT_LONG_PRESSED 页面达到长按时间 长按进入工程设置或隐藏菜单 常用于维护入口
LV_EVENT_LONG_PRESSED_REPEAT 长按后周期性重复触发 连续加减、持续执行操作 高频事件，避免页面跳转等重复动作

页面事件注意事项

  • 页面中有按钮、开关等子控件时，页面级点击事件可能受到事件冒泡影响；不要让点击子控件时意外触发页面跳转。
  • 在 SCREEN_LOAD_START 或 SCREEN_LOADED 中自动跳转时，要检查目标页事件，避免两个页面互相自动跳转形成死循环。
  • PRESSING、SCROLL、LONG_PRESSED_REPEAT 都可能高频触发，不要绑定重复创建页面或反复跳转的动作。
  • SCREEN_UNLOADED 发生时页面可能已经被清理；运行时回调不要继续访问失效的页面或控件指针。
  • 一个页面可以配置多个事件，但每个事件都应有清晰描述，便于导出代码后追踪逻辑。

十五、零基础上手路线

推荐学习顺序：先让屏幕亮起来，再让鼠标或触摸有反应，最后才做复杂控件和动画。每次只验证一个环节，排错会简单很多。

1初始化

先调用 lv_init()，它必须早于其他 LVGL API。

2时间基准

用 lv_tick_set_cb() 或周期性 lv_tick_inc() 告诉 LVGL 已经过了多少毫秒。

3显示接口

创建显示、设置绘制缓冲区，并在 flush 回调中把像素送到 LCD。

4输入设备

注册触摸、鼠标、按键或编码器的读取回调。

5创建界面

创建 Screen 和控件，设置位置、尺寸、文字与样式。

6绑定事件

用 lv_obj_add_event_cb() 把点击、长按和值变化连接到业务逻辑。

7驱动任务

主循环或任务中持续调用 lv_timer_handler()。

硬件/SDL→显示与输入驱动→LVGL 对象树→事件回调→业务功能

十六、先看懂 LVGL 的运行架构

层次新手理解典型 API / 文件
平台层 Platform系统时钟、延时、GPIO、LCD、触摸、文件系统platform_get_ms()、LCD/SPI/DMA 驱动
接口层 Driver把平台能力翻译成 LVGL 能识别的显示和输入接口lv_display_set_flush_cb()、lv_indev_set_read_cb()
GUI 引擎管理对象树、布局、绘制、事件、动画和定时器lv_timer_handler()
界面层 UIDesigner 导出的页面与控件init_page_xxx()、bk_lv_ui_t
业务层 App拍照、相册、视频、设置等真正功能自定义函数和回调文件
关键观念：Designer 负责“控件是什么、长什么样、什么时候触发”；业务层负责“拍照、读 SD 卡、切换视频等具体工作”。不要把硬件驱动直接堆进自动生成的页面文件。

十七、初始化、Tick 与主循环 API

最小启动骨架（LVGL 9.x）

#include "lvgl.h"

static uint32_t platform_get_ms(void)
{
    return board_millis();   /* 返回开机后的毫秒数 */
}

int main(void)
{
    board_init();
    lv_init();

    lv_tick_set_cb(platform_get_ms);
    display_init();
    input_init();
    ui_create();

    while (1) {
        lv_timer_handler();
        board_delay_ms(5);
    }
}
API用途容易犯的错误
lv_init()初始化 LVGL，全程调用一次在它之前创建控件
lv_tick_set_cb(cb)注册系统毫秒计时函数回调返回的不是毫秒，或时间会倒退
lv_tick_inc(ms)另一种 Tick 提供方式，周期累加经过的毫秒与 lv_tick_set_cb() 同时使用
lv_timer_handler()处理重绘、输入、事件、动画和定时器调用间隔太长，导致卡顿和长按失灵
lv_delay_ms(ms)在支持的平台上提供简单延时在实时任务里长时间阻塞
不要这样写：先运行 lv_timer_handler()，再固定执行 lv_tick_inc(5) 和延时 5ms。处理函数本身也消耗时间，累计出来的 Tick 会逐渐不准。

十八、显示接口 Display API

显示接入有三个核心信息：屏幕分辨率和颜色格式、LVGL 在哪里画、画完后怎样把像素送到屏幕。

#define LCD_HOR_RES  320
#define LCD_VER_RES  242

static uint8_t draw_buf[LCD_HOR_RES * 20 * 2]; /* RGB565，缓存 20 行 */

static void lcd_flush(lv_display_t * display,
                      const lv_area_t * area,
                      uint8_t * px_map)
{
    int32_t width  = area->x2 - area->x1 + 1;
    int32_t height = area->y2 - area->y1 + 1;

    board_lcd_blit(area->x1, area->y1, width, height, px_map);
    lv_display_flush_ready(display); /* DMA 异步时，应在 DMA 完成后调用 */
}

static lv_display_t * display_init(void)
{
    lv_display_t * display = lv_display_create(LCD_HOR_RES, LCD_VER_RES);
    lv_display_set_buffers(display, draw_buf, NULL, sizeof(draw_buf),
                           LV_DISPLAY_RENDER_MODE_PARTIAL);
    lv_display_set_flush_cb(display, lcd_flush);
    return display;
}
API / 类型中文说明检查点
lv_display_create(w, h)创建一个显示对象宽高必须与实际方向一致
lv_display_set_buffers()指定绘制缓冲区和渲染模式参数是字节数，不是像素数
LV_DISPLAY_RENDER_MODE_PARTIAL分块刷新，适合 RAM 较小的 MCU缓冲区至少能容纳若干完整行
lv_display_set_flush_cb()注册刷屏回调每次刷新最终都要通知完成
lv_display_flush_ready()告诉 LVGL 本次传输结束漏调会让刷新停住

十九、输入设备 Input Device API

鼠标或触摸屏

static void pointer_read(lv_indev_t * indev, lv_indev_data_t * data)
{
    int16_t x, y;
    bool pressed = board_pointer_read(&x, &y);

    data->point.x = x;
    data->point.y = y;
    data->state = pressed ? LV_INDEV_STATE_PRESSED
                          : LV_INDEV_STATE_RELEASED;
}

static lv_indev_t * input_init(void)
{
    lv_indev_t * indev = lv_indev_create();
    lv_indev_set_type(indev, LV_INDEV_TYPE_POINTER);
    lv_indev_set_read_cb(indev, pointer_read);
    return indev;
}
类型适用设备常见事件
LV_INDEV_TYPE_POINTER触摸屏、触摸板、鼠标CLICKED、PRESSED、GESTURE
LV_INDEV_TYPE_KEYPAD方向键、确认键、矩阵键盘LV_EVENT_KEY
LV_INDEV_TYPE_ENCODER旋钮 + 按压焦点移动、编辑数值、确认
LV_INDEV_TYPE_BUTTON固定位置的物理按键把按键映射到屏幕坐标
鼠标点不到小图标？保留控件原尺寸，可以用 lv_obj_set_ext_click_area(obj, 12) 扩大命中区域，不改变视觉布局。

二十、对象树与常用控件 API

LVGL 界面是一棵对象树。创建函数的参数通常是父对象；父对象删除时，它的子对象会一起删除。

lv_obj_t * screen = lv_obj_create(NULL);
lv_obj_t * button = lv_button_create(screen);
lv_obj_t * label  = lv_label_create(button);

lv_label_set_text(label, "Open album");
lv_obj_set_size(button, 140, 48);
lv_obj_center(button);
lv_obj_center(label);

lv_screen_load(screen);
API用途备注
lv_obj_create(parent)创建基础对象或容器parent == NULL 时创建 Screen
lv_button_create(parent)创建按钮适合文字操作按钮
lv_image_create(parent)创建图片需要点击时记得加 CLICKABLE 或使用图片按钮
lv_label_create(parent)创建文本标签再调用 lv_label_set_text()
lv_obj_set_pos()设置相对父对象的位置绝对布局常用
lv_obj_set_size()设置宽高也可使用 lv_pct()
lv_obj_align()相对父对象对齐如 LV_ALIGN_CENTER
lv_obj_delete()删除对象及其子对象删除后不要继续使用旧指针
lv_obj_add_flag()增加行为标志如 LV_OBJ_FLAG_CLICKABLE
lv_obj_remove_flag()移除行为标志如关闭滚动能力

二十一、事件回调 API：把界面接到功能

static void album_button_cb(lv_event_t * e)
{
    lv_event_code_t code = lv_event_get_code(e);
    lv_obj_t * target = lv_event_get_target_obj(e);
    void * user_data = lv_event_get_user_data(e);

    if (code == LV_EVENT_CLICKED) {
        app_open_album();
    }
}

lv_obj_add_event_cb(album_button, album_button_cb,
                    LV_EVENT_CLICKED, NULL);
API作用使用建议
lv_obj_add_event_cb()给控件注册回调最后一个参数可传业务上下文
lv_event_get_code()取得当前事件类型监听 LV_EVENT_ALL 时必须判断
lv_event_get_target_obj()取得事件目标控件适合多个控件共用一个回调
lv_event_get_user_data()取得注册时传入的数据不要传局部变量的失效地址
lv_obj_send_event()主动向控件发送事件硬件键模拟点击时可用，但更推荐调用共享业务动作
单击和长按的关系：长按后释放，有些输入流程仍可能产生其他事件。若两个动作互斥，应在业务层记录“已经长按处理”，释放时不要再次执行短按动作。

二十二、Screen 页面切换 API

static lv_obj_t * gallery_screen;

void open_gallery(void)
{
    if (gallery_screen == NULL) {
        gallery_screen = create_gallery_screen();
    }

    lv_screen_load_anim(gallery_screen,
                        LV_SCR_LOAD_ANIM_MOVE_LEFT,
                        300,   /* 动画时间 ms */
                        0,     /* 延迟 ms */
                        false  /* 是否自动删除旧页面 */);
}
Designer 动作运行时概念说明
navigate_pagelv_screen_load_anim()切换到目标 Screen
animationTypeLV_SCR_LOAD_ANIM_*淡入、覆盖、移动等切换方式
duration动画时长常用 200～400ms
delay切换延迟启动页常用
autoDel自动删除旧 Screen节省内存，但旧页状态也会丢失

内存陷阱：反复创建新页面却不删除，会持续占用堆内存；自动删除旧页后，又不能继续持有它内部控件的旧指针。

二十五、物理按键与鼠标共用一套逻辑

最稳妥的结构是：鼠标事件和物理按键都调用同一个“动作函数”，避免写两套跳转逻辑。

typedef enum {
    UI_KEY_CAMERA, UI_KEY_VIDEO, UI_KEY_UP,
    UI_KEY_DOWN, UI_KEY_OK
} ui_key_t;

static void ui_action_open_video(void)
{
    app_navigate_to_video();
}

static void video_icon_clicked(lv_event_t * e)
{
    if (lv_event_get_code(e) == LV_EVENT_CLICKED) {
        ui_action_open_video();          /* 鼠标/触摸入口 */
    }
}

void ui_handle_key(ui_key_t key)
{
    switch (key) {
    case UI_KEY_VIDEO:
        ui_action_open_video();          /* K6 物理按键入口 */
        break;
    case UI_KEY_UP:
        app_select_previous();            /* K7 */
        break;
    case UI_KEY_DOWN:
        app_select_next();                /* K13 */
        break;
    case UI_KEY_OK:
        app_confirm();                     /* K8 */
        break;
    case UI_KEY_CAMERA:
        app_take_photo();                  /* K2 */
        break;
    }
}

K6 视频ui_action_open_video()点击视频入口图标

二十六、Designer 导出工程：哪里能改

区域建议原因
Designer 页面、控件、属性、事件在 Designer 中修改它是界面的源数据
自动生成的 *_init.c尽量不要长期手改重新导出时通常会覆盖
custom_func.c/.h 或用户代码区放自定义业务入口便于保留与维护
LCD、触摸、GPIO、SD、摄像头驱动放在独立平台模块避免与 UI 生成代码耦合
页面跳转与业务状态机集中在 UI 控制器鼠标和硬件键可复用

推荐目录

project/
├─ beken_generated/      # Designer 导出内容
├─ ui_logic/             # 页面流程、共享动作、状态机
├─ drivers/              # LCD、触摸、按键、SD、摄像头
├─ services/             # 相册索引、视频播放、存储服务

二十八、完整练习：按钮计数器

这个例子把对象、样式、事件和动态文字串在一起。先在 PC 模拟器跑通，再移植到硬件。

#include "lvgl.h"

static lv_obj_t * count_label;
static uint32_t count;

static void count_button_cb(lv_event_t * e)
{
    if (lv_event_get_code(e) != LV_EVENT_CLICKED) return;

    count++;
    lv_label_set_text_fmt(count_label, "Count: %lu",
                          (unsigned long)count);
}

void ui_create(void)
{
    lv_obj_t * screen = lv_obj_create(NULL);
    lv_screen_load(screen);

    count_label = lv_label_create(screen);
    lv_label_set_text(count_label, "Count: 0");
    lv_obj_align(count_label, LV_ALIGN_CENTER, 0, -36);

    lv_obj_t * button = lv_button_create(screen);
    lv_obj_set_size(button, 140, 48);
    lv_obj_align(button, LV_ALIGN_CENTER, 0, 28);
    lv_obj_set_style_radius(button, 10, LV_PART_MAIN);
    lv_obj_add_event_cb(button, count_button_cb,
                        LV_EVENT_CLICKED, NULL);

    lv_obj_t * text = lv_label_create(button);
    lv_label_set_text(text, "Click me");
    lv_obj_center(text);
}

三十三、图片、字体与中文显示

图片的三种来源

来源代码适用场景
C 数组LV_IMAGE_DECLARE(icon);
lv_image_set_src(img, &icon);		小图标、Logo；启动稳定，但占 Flash
外部文件lv_image_set_src(img, "S:photos/p001.bin");SD 相册、大量图片；需要文件系统与解码支持
LVGL Symbollv_image_set_src(img, LV_SYMBOL_OK);轻量单色图标；外观随字体变化

字体使用原则

  • Montserrat 一类西文字体通常不包含中文，中文界面必须选择包含中文字形的字体。
  • 字体越大、字符范围越广，占用的 Flash 越多；嵌入式项目可只生成实际需要的字符。
  • 动态文本若可能出现任意姓名或文件名，字符集要覆盖真实输入范围。
  • 运行时加载字体可节省固件空间，但需要文件系统、内存和错误回退方案。

三十五、RTOS、线程与中断安全

推荐只让一个 GUI 任务调用 LVGL。摄像头、SD 和视频任务完成工作后，通过队列把消息发给 GUI 任务，由 GUI 任务更新控件。

摄像头/SD 任务→消息队列→GUI 任务→LVGL API
void gui_task(void * arg)
{
    ui_message_t msg;

    for (;;) {
        while (queue_try_receive(&msg)) {
            ui_process_message(&msg); /* 这里可以安全更新 UI */
        }

        lv_timer_handler();
        rtos_delay_ms(5);
    }
}

如果工程已经启用 LVGL 的 OS 适配，并且确实要从其他任务调用 LVGL，可按工程配置使用锁：

lv_lock();
lv_label_set_text(status_label, "Photo saved");
lv_unlock();
场景推荐做法不要做
GPIO 中断记录键值或发送队列在 ISR 中创建控件或切页
摄像头帧完成发送“新帧可用”消息在 DMA 回调里直接修改 Image
SD 扫描结束把结果交给 GUI 任务刷新列表持锁执行长时间文件扫描
事件回调/定时器执行短小 UI 操作阻塞等待硬件或网络

三十六、内存、刷新与性能优化

问题先检查优化方向
切页越来越慢是否反复创建页面、定时器和事件复用页面或在销毁时完整释放
相册占 RAM 太多是否同时解码多张全屏图片只保留当前图和必要预读图
刷新撕裂DMA、双缓冲和 flush 完成时机确认缓冲区生命周期与同步
动画卡顿GUI 任务是否被文件读取阻塞把 I/O 移到工作任务，降低无意义重绘
Flash 过大字体字符范围和图片格式裁剪字体字符集、压缩或外置资源
CPU 占用高是否持续改变大面积透明对象减少全屏透明叠层、阴影和频繁动画

快速估算

RGB565 全屏缓冲 ≈ 宽 × 高 × 2 字节
320 × 242 × 2 = 154,880 字节（约 151 KiB）

20 行局部缓冲 ≈ 320 × 20 × 2
              = 12,800 字节（约 12.5 KiB）
优化顺序：先测量，再优化。先确认瓶颈属于 CPU、RAM、Flash、显示总线还是文件读取，避免为了省几字节把代码变得难以维护。

三十九、自测题：真的理解了吗

1. 哪个函数必须在其他 LVGL API 之前调用？

答案 B。LVGL 初始化完成后才能创建显示、输入设备和控件。

2. flush 回调完成像素传输后必须做什么？

答案 C。没有完成通知，LVGL 会认为传输仍在进行。

3. Switch 的值变化通常监听哪个事件？

答案 A。滑块、开关、下拉框和滚轮都常用 VALUE_CHANGED。

4. RTOS 中摄像头任务要更新 Label，首选做法是什么？

答案 C。单一 GUI 任务最容易保证线程安全和可维护性。

5. 页面启用自动删除后，最危险的错误是什么？

答案 B。对象删除后，旧指针已经失效。

6. 相册要显示 S:photos/p001.bin，最先要确保什么？

答案 A。路径映射、文件读取和图片解码缺一不可。
