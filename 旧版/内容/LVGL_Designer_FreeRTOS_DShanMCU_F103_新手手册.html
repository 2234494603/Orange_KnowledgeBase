给新手的 LVGL Designer + FreeRTOS STM32F103 小手册

离线搜索 LVGL UI Designer DShanMCU-F103 / STM32F103 FreeRTOS 入门

这份文档把你原来的 LVGL UI Designer 中英术语/API 手册，和 100ASK FreeRTOS DShanMCU-F103 学习路线融合起来。目标很简单：新手先知道 Designer 每个词是什么意思，再知道这些事件怎样落到 FreeRTOS 任务、队列、按键、屏幕和 SD 卡里。

一、先建立整体地图

Designer 画界面→ 导出 LVGL 代码→ FreeRTOS 分任务→ 驱动屏幕/按键/SD 卡→ 用队列把硬件事件送到 UI

刚开始不要急着背 API。你只需要抓住一句话：Designer 负责“长什么样、点击哪里”，FreeRTOS 负责“谁在后台干活、谁把消息送给谁”，LVGL 负责“把界面画到屏幕上并处理事件”。

1界面层

页面、控件、样式、状态、事件。比如点击相册按钮进入相册页。

2系统层

任务、队列、互斥锁、事件组、软件定时器。比如按键任务把 K8 的确认事件发给 UI 任务。

3硬件层

LCD、触摸或按键、摄像头、SD 卡、串口调试。比如拍照后把文件写入 SD 卡。

新手建议：先用电脑模拟器把页面跳转和鼠标点击跑通，再上板接真实 K2、K6、K7、K13、K8 按键。这样问题会少一半。

二、Designer 常见术语中英对照

英文中文新手理解常见 API/概念
Property属性控件本身的数据：位置、大小、文字、数值。lv_obj_set_x、lv_label_set_text
Style样式控件看起来怎样：颜色、边框、字体、圆角。lv_obj_set_style_bg_color
Part样式部件一个控件内部可以分区设置样式，例如滑块主体和指示条。LV_PART_MAIN、LV_PART_INDICATOR
State状态控件处于普通、按下、选中、禁用等状态。LV_STATE_DEFAULT、LV_STATE_PRESSED
Event事件什么时候触发逻辑：点击、长按、值改变、页面加载。lv_obj_add_event_cb
Action动作事件发生后做什么：跳转页面、隐藏控件、执行自定义函数。Designer 动作 / C 回调函数
Screen页面/屏幕一个完整界面，例如启动页、图传页、相册页。lv_screen_load、lv_screen_load_anim
Image Button图片按钮看起来是图标，本质可以点击，适合相机/相册/上下翻。lv_imagebutton_create
Flags标志控制可点击、可滚动、隐藏等行为。LV_OBJ_FLAG_CLICKABLE、LV_OBJ_FLAG_HIDDEN
Animation动画让页面或控件有淡入、移动、缩放等变化。lv_anim_t、lv_screen_load_anim
最容易混的地方：pressed 是视觉状态，LV_EVENT_PRESSED 才是事件；style 改外观，event 改逻辑。

三、事件类型和页面动作

事件中文什么时候用项目例子
LV_EVENT_CLICKED单击/点击完成按钮最常用事件，按下再松开后触发。点击相册图标进入相册。
LV_EVENT_PRESSED按下手指或鼠标刚按下时触发。按下图标时改变颜色。
LV_EVENT_PRESSING正在按住持续按住期间反复触发。长按连续快进，谨慎使用。
LV_EVENT_LONG_PRESSED长按按住超过阈值后触发一次。长按 SD 图标进入相册。
LV_EVENT_LONG_PRESSED_REPEAT长按重复长按后周期性重复触发。连续上一张/下一张。
LV_EVENT_RELEASED释放按键松开时触发。停止连续动作。
LV_EVENT_VALUE_CHANGED值改变滑块、开关、下拉框改变。亮度滑块改变背光。
LV_EVENT_SCREEN_LOADED页面加载完成进入页面后初始化内容。相册页加载第一张照片。
LV_EVENT_SCREEN_UNLOADED页面卸载完成离开页面后释放资源。离开视频页后停止解码。
LV_EVENT_DELETE对象删除控件被删除时清理资源。清理图片缓存。

页面跳转的两种写法

// 直接切换页面
lv_screen_load(B_Video_Link_Screen_3000_06_4302644);

// 带一点消失感/淡入淡出
lv_screen_load_anim(B_Video_Link_Screen_3000_06_4302644,
                    LV_SCR_LOAD_ANIM_FADE_ON,
                    300, 0, false);

Designer 里可以配置“页面跳转”动作；如果 Designer 开放“自定义函数事件”，也可以让按钮事件调用你导出代码里的 C 函数。

四、FreeRTOS 先学哪几个概念

概念中文解释常用函数和 LVGL 的关系
Task任务，像同时运行的“小程序”。xTaskCreate、vTaskDelay通常单独建一个 UI 任务周期调用 lv_timer_handler。
Queue队列，用来在线程之间传递消息。xQueueCreate、xQueueSend、xQueueReceive按键任务把按键事件发给 UI 任务。
Semaphore信号量，用来通知或计数。xSemaphoreCreateBinary、xSemaphoreGiveDMA 刷屏完成后通知等待方。
Mutex互斥量，保护共享资源。xSemaphoreCreateMutex、xSemaphoreTake保护 LVGL 调用或文件系统访问。
Event Group事件组，用多个 bit 表示多个条件。xEventGroupSetBits、xEventGroupWaitBits等待 SD 卡就绪、摄像头就绪、屏幕就绪。
Task Notification任务通知，轻量级的一对一通知。xTaskNotifyGive、ulTaskNotifyTake适合 ISR 通知某个任务处理。
Software Timer软件定时器，周期执行轻量逻辑。xTimerCreate、xTimerStart定时刷新状态栏电量、录制时间。
ISR API中断专用 API，名字常带 FromISR。xQueueSendFromISR按键中断里不要直接操作 UI，发消息即可。
重点纪律：LVGL 不是随便哪个任务都能乱调。新手最稳的结构是：只有 UI 任务直接调用 LVGL，其他任务通过队列发消息给 UI 任务。

五、推荐的软件结构

按键/触摸任务→ Queue UI 任务→ LVGL 页面跳转
摄像头任务→ Queue/EventGroup 图传页→ 更新状态图标
SD 卡/文件任务→ Queue 相册页→ 上一张/下一张/循环播放 
typedef enum {
    UI_MSG_KEY_CAMERA,
    UI_MSG_KEY_VIDEO,
    UI_MSG_KEY_UP,
    UI_MSG_KEY_DOWN,
    UI_MSG_KEY_OK,
    UI_MSG_SD_READY,
    UI_MSG_PHOTO_SAVED,
    UI_MSG_ERROR
} ui_msg_id_t;

typedef struct {
    ui_msg_id_t id;
    uint32_t value;
} ui_msg_t;

static QueueHandle_t ui_queue;

static void ui_task(void *arg)
{
    ui_msg_t msg;

    while (1) {
        while (xQueueReceive(ui_queue, &msg, 0) == pdTRUE) {
            ui_handle_message(&msg);
        }

        lv_timer_handler();
        vTaskDelay(pdMS_TO_TICKS(5));
    }
}

这段结构非常适合你的项目：K2/K6/K7/K13/K8 最终都变成 ui_msg_t，鼠标点击模拟也调用同一套 ui_handle_message，这样模拟器和真板逻辑不会分叉。

六、LVGL 移植到 STM32F103 的关键接口

接口作用新手要检查什么
lv_init()初始化 LVGL 内部模块。必须在创建任何控件之前调用。
lv_tick_inc(ms)告诉 LVGL 经过了多少毫秒。一般放在 1ms 定时器或 SysTick 回调里。
lv_timer_handler()让 LVGL 处理动画、输入、刷新。UI 任务里周期调用，常见 5ms 左右。
display flush把 LVGL 的颜色缓冲区刷到 LCD。刷完必须通知 LVGL，本版本接口名以项目头文件为准。
input read读取触摸、鼠标、按键。模拟器读鼠标，上板读 GPIO/ADC/触摸芯片。
file system让 LVGL 或业务读取图片文件。SD 卡通常接 FatFS，注意路径和缓存。
 
void app_lvgl_init(void)
{
    lv_init();
    board_lcd_init();
    board_input_init();

    app_lvgl_display_register();
    app_lvgl_input_register();

    ui_init();   // Designer 导出的界面初始化
}
接口名提醒：LVGL 8 和 LVGL 9 的显示/输入注册 API 有差异，最终以你工程里实际包含的 lvgl.h 和 Designer 导出的代码为准。

{

八、鼠标点击模拟硬件按键

模拟阶段不要急着接 GPIO。把每个图片按钮的点击事件都转换成同一套 UI 消息，后面上板时只要让真实按键也发同样的消息即可。

static void send_ui_msg(ui_msg_id_t id)
{
    ui_msg_t msg = { .id = id, .value = 0 };
    xQueueSend(ui_queue, &msg, 0);
}

static void on_album_next_clicked(lv_event_t *e)
{
    send_ui_msg(UI_MSG_KEY_DOWN);
}

static void on_album_prev_clicked(lv_event_t *e)
{
    send_ui_msg(UI_MSG_KEY_UP);
}

static void on_back_long_pressed(lv_event_t *e)
{
    send_ui_msg(UI_MSG_KEY_OK);
}
这样做的好处：鼠标、触摸、真实按键最后都走一套业务函数。你测通跳转逻辑后，接硬件按键时不需要重写 UI。

九、CubeMX 和工程创建路线

开发环境

准备 Keil MDK、STM32CubeMX、STM32CubeProgrammer。先能编译下载空工程，再加 FreeRTOS。

时钟和调试

配置 HSE/SYSCLK、SWD 调试接口、串口打印。调试口不要被普通 GPIO 占用。

外设模块

LCD、按键、SD 卡、串口、定时器逐个验证。每加一个模块就编译一次。

FreeRTOS

先建 LED 任务和串口打印任务，确认调度正常，再加入 LVGL UI 任务。

阶段成功标志失败时先看
裸机空工程能下载，LED 或串口能工作。时钟、下载器、启动文件、工程路径。
FreeRTOS 工程两个任务能交替打印。堆大小、任务栈、优先级、SysTick。
LCD 驱动能刷纯色和矩形。SPI/FSMC、复位脚、背光、颜色格式。
LVGL 工程能显示一个标签或按钮。lv_tick_inc、flush 完成通知、缓冲区。
Designer 工程能显示导出的页面。文件是否加入工程、资源路径、字体图片资源。

十、任务、优先级和延时的经验值

任务建议优先级周期/阻塞方式注意
UI 任务中等偏高lv_timer_handler() 后延时 5ms不要做耗时文件扫描。
按键任务中等10-20ms 扫描或中断通知消抖后发队列。
摄像头任务较高按帧或事件阻塞不要直接改 UI 控件。
SD 卡任务中等偏低队列触发文件读写加互斥锁。
状态刷新任务较低500ms-1000ms电量、SD 状态、录制时间。

新手常犯的错是把所有事情都塞进 UI 回调：点击按钮后立刻扫描 SD 卡、解码图片、写文件。正确做法是 UI 回调只发命令，耗时事情交给后台任务，完成后再发消息回 UI。

十一、队列、互斥锁、事件组怎么选

需求推荐工具例子为什么
传递一个按键或命令队列K8 确认、K7 上翻有顺序、有数据、好调试。
保护同一个资源互斥锁SD 卡文件系统、LVGL 调用一次只允许一个任务访问。
等待多个条件事件组等待 LCD + SD + Camera 就绪多个 bit 可以组合等待。
中断叫醒一个任务任务通知DMA 完成、按键中断轻量，速度快。
周期刷新软件定时器/低优先级任务每秒更新录制时间逻辑简单，不阻塞 UI。
 
static SemaphoreHandle_t lvgl_mutex;

void ui_safe_call(void (*fn)(void))
{
    if (xSemaphoreTake(lvgl_mutex, pdMS_TO_TICKS(50)) == pdTRUE) {
        fn();
        xSemaphoreGive(lvgl_mutex);
    }
}
更稳的新手做法：如果能做到“只有 UI 任务调用 LVGL”，就可以少用很多锁；锁是保护伞，不是把复杂结构变简单的魔法。

十二、相册和 SD 卡逻辑

相册页最适合用“文件列表 + 当前索引”模型。进入相册时扫描 SD 卡，保存图片路径数组；上一张和下一张只改变索引并刷新图片。

static int gallery_index;
static int gallery_count;

static int wrap_index(int index, int count)
{
    if (count <= 0) return 0;
    if (index < 0) return count - 1;
    if (index >= count) return 0;
    return index;
}

void gallery_show_next(void)
{
    gallery_index = wrap_index(gallery_index + 1, gallery_count);
    gallery_reload_current_image();
}

void gallery_show_prev(void)
{
    gallery_index = wrap_index(gallery_index - 1, gallery_count);
    gallery_reload_current_image();
}
情况界面应该怎样表现代码要防什么
没有 SD 卡显示“未检测到 SD 卡”或灰掉相册入口。不要扫描空指针路径。
目录为空显示空状态，不允许上一张下一张崩溃。gallery_count == 0。
图片损坏跳过或显示错误提示。解码失败返回值。
播放循环最后一张下一张回第一张。索引越界。

十四、常见编译和运行问题

现象常见原因排查顺序
编译找不到 LVGL 头文件Include Path 没加。检查 lvgl.h 路径、Designer 导出路径。
界面不刷新没有调用 tick 或 handler。看 lv_tick_inc、lv_timer_handler。
屏幕花屏颜色格式、分辨率、刷新窗口错误。先刷纯色，再刷矩形，再接 LVGL。
点击没反应控件不可点击或输入设备没注册。检查 LV_OBJ_FLAG_CLICKABLE 和 indev read。
切页后崩溃页面对象未创建、重复释放、资源路径错。确认 Designer 初始化顺序和页面变量。
随机 HardFault任务栈不足、数组越界、ISR API 用错。开栈监测、查 FromISR API。
中文乱码字体不包含中文字库。换中文字体资源，确认编码 UTF-8。

十五、Designer 控件速查

控件中文适合场景常用事件
label标签显示文字、状态、电量、提示。通常无事件。
button按钮普通命令按钮。LV_EVENT_CLICKED
imagebutton图片按钮相机、相册、上下翻图标。CLICKED、LONG_PRESSED
image图片背景图、相册图片、状态图标。通常无事件，除非设置可点击。
slider滑块亮度、音量、进度。VALUE_CHANGED
switch开关开/关设置。VALUE_CHANGED
dropdown下拉框模式选择、分辨率选择。VALUE_CHANGED
obj基础容器做面板、分组、列表项。可有可无。

十六、一个推荐的学习顺序

1第 1 天

只看 Designer：属性、样式、状态、事件、动作。完成两个页面互跳。

2第 2 天

学 FreeRTOS 任务和队列。写两个任务，一个发消息，一个收消息。

3第 3 天

把 LVGL 放进 UI 任务。显示 Designer 导出的首页。

4第 4 天

接按键：K2/K6/K7/K13/K8 发队列消息，模拟鼠标逻辑迁移到真板。

5第 5 天

6第 6 天

整理工程：注释、错误提示、任务栈检查、打印日志。

十七、100ASK FreeRTOS 章节对照

100ASK 章节本手册对应能力建议怎么学
课程介绍、程序设计模式理解从裸机 while 循环到多任务的变化。先理解“为什么需要 RTOS”。
开发环境、开发板使用能编译、下载、调试 DShanMCU-F103 工程。不要跳过环境验证。
模块使用说明与 CubeMX 配置把 GPIO、串口、定时器、SD 卡等外设配好。一个模块一个模块验证。
创建 FreeRTOS 工程、源码概述知道工程里哪些文件属于内核、哪些属于移植层。先会用，再慢慢读源码。
内存管理、任务管理会建任务，知道栈和堆为什么会出问题。重点看任务栈和 heap_4。
队列、信号量、互斥量、事件组、任务通知会让任务之间安全通信。优先掌握队列和互斥量。
软件定时器、中断管理、资源管理会处理周期任务、中断延迟处理和共享资源。注意 FromISR API。
调试与优化会用打印、断言、任务统计查问题。每个阶段保留可观察日志。
